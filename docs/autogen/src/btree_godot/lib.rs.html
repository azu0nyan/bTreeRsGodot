1//! # btree_godot — Godot behavior-tree nodes for [`btree`]
2//!
3//! This crate is the Godot ([gdext](https://godot-rust.github.io)) adapter for
4//! the engine-agnostic [`btree`] library. `btree` itself never
5//! references Godot; everything that does — playing an animation, calling a
6//! method on a scene node, evaluating a Godot `Expression` — lives here.
7//!
8//! The node set mirrors the engine-coupled tasks of the
9//! [LimboAI](https://github.com/limbonaut/limboai) addon. Pure-logic tasks
10//! (sequences, fallbacks, decorators, timers, randomness) are *not* duplicated
11//! here — they are in [`btree`] and reachable through the
12//! [`prelude`].
13//!
14//! ## Capability traits
15//!
16//! Following `btree`'s pattern of bounding a node on what it needs from the
17//! context `D`, the Godot nodes are gated on small traits the agent implements:
18//!
19//! * [`HasAnimationPlayer`] — hands out a `Gd<AnimationPlayer>`; required by the
20//!   animation nodes ([`PlayAnimation`], [`AwaitAnimation`], [`PauseAnimation`],
21//!   [`StopAnimation`]).
22//! * [`HasAgent`] — hands out a `Gd<Node>`; required by the nodes that act on a
23//!   scene node ([`CallMethod`], [`CheckAgentProperty`], [`SetAgentProperty`],
24//!   [`EvaluateExpression`]).
25//!
26//! [`ConsolePrint`] needs nothing and works over any `D`.
27//!
28//! ## Wiring
29//!
30//! Make your blackboard / agent type implement the capability traits, then
31//! build trees from both crates and tick them from `_process`:
32//!
33//! ```ignore
34//! use btree_godot::prelude::*;
35//! use godot::prelude::*;
36//! use godot::classes::AnimationPlayer;
37//!
38//! struct Blackboard {
39//!     player: Gd<AnimationPlayer>,
40//!     agent: Gd<Node>,
41//!     delta: f64,
42//! }
43//!
44//! impl HasAnimationPlayer for Blackboard {
45//!     fn animation_player(&self) -> Gd<AnimationPlayer> { self.player.clone() }
46//! }
47//! impl HasAgent for Blackboard {
48//!     fn agent(&self) -> Gd<Node> { self.agent.clone() }
49//! }
50//! impl HasDelta for Blackboard {
51//!     fn delta_seconds(&self) -> f64 { self.delta } // HasDelta comes from `btree`
52//! }
53//!
54//! // `Sequence`, `Wait` are from `btree`; `PlayAnimation` is from here.
55//! let mut tree = Sequence::new(nodes![
56//!     PlayAnimation::new("attack"),
57//!     Wait::new(0.5),
58//!     ConsolePrint::new("done"),
59//! ]);
60//! // each frame: bb.delta = delta; tree.tick(&mut bb, None);
61//! ```
