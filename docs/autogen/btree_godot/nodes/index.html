Godot-coupled behavior-tree nodes — one type per submodule.

Each type implements btree::BehaviorNode over a context D and is bounded on the capability trait it needs (see crate::caps):

  • Animation (D: HasAnimationPlayer): PlayAnimation, AwaitAnimation, PauseAnimation, StopAnimation.
  • Agent (D: HasAgent): CallMethod, CheckAgentProperty, SetAgentProperty, EvaluateExpression.
  • Console (any D): ConsolePrint.

They are re-exported at the crate root and from the prelude.
